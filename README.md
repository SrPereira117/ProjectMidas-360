ProjectMidas 360 (Native GoldenEye 007 for Xbox 360)
1. Copy the ProjectMidas360 folder—extracted from the downloaded .zip file—to your flash drive or hard drive.
2. Place your own GoldenEye 007 (USA) ROM—12 MB in size, in .z64, .v64, or .n64 format—inside that folder (you may name the file whatever you like).
3. Launch ProjectMidas360.xex via Aurora or Freestyle.
Hold the BACK button for 2 seconds to exit. The midas.ini.example file is optional (rename it to midas.ini to customize settings).
This port does not include any ROMs or game files.

ProjectMidas 360 (GoldenEye 007 nativo para o Xbox 360)
1. Copie a pasta ProjectMidas360 que você extraiu do .zip baixado para o pendrive/HD.
2. Coloque dentro dela a SUA ROM de GoldenEye 007 (USA), 12 MB (.z64/.v64/.n64), com qualquer nome.
3. Abra ProjectMidas360.xex pelo Aurora/Freestyle.
Segure BACK por 2 s para sair. midas.ini.example é opcional (renomeie para midas.ini para personalizar).
Este port nao contem ROM nem arquivos do jogo.
